# Bookmarks 🔖

**Bookmarks** — лёгкий личный менеджер закладок, который работает на вашем
собственном сервере (Ubuntu Server, systemd). Сохраняйте ссылки в группы,
помечайте избранное, ищите по тегам и открывайте сайты в один клик.
Все данные хранятся в одной SQLite-базе на вашем сервере: никаких внешних
сервисов, подписок и чужих облаков.

## Возможности

- **Группы, теги и избранное** — любая организация ваших ссылок
- **Мгновенный поиск** — по названию, описанию и тегам
- **Несколько пользователей** — личные аккаунты с индивидуальными лимитами (квотами)
- **Админ-панель** — управление пользователями, квоты, блокировка аккаунтов
- **PWA** — интерфейс можно «установить» как приложение на телефон или компьютер
- **Светлая и тёмная тема**, интерфейс на русском и английском языках
- **Автообновление** — прямо из пункта «О программе»
- **Онлайн-бэкап базы** с ротацией старых копий

Требования: Ubuntu Server 22.04/24.04, Python 3.10+
(если Python нет — установочный скрипт поставит его сам).

## Установка

1. Получите папку `ubuntu_sp` на сервере (например, в домашнюю директорию):

   ```bash
   cd ~
   git clone https://github.com/evgeniy7f2/Bookmarks.git
   ```

   или скачайте архив с GitHub. Убедитесь, что перед вами папка, в которой
   лежат `install.sh`, `app.py` и `bookmarks/`.

2. Запустите установщик:

   ```bash
   cd <папка с install.sh>
   sudo bash install.sh
   ```

3. Ответьте на три вопроса (Enter — принять значение по умолчанию):

   | Вопрос | По умолчанию | Что означает |
   |---|---|---|
   | Каталог установки | `/opt/bookmarks` | где будут файлы программы и данные |
   | Порт | `8765` | TCP-порт для HTTP |
   | Доступ | `external` | `internal` — только с самого сервера (127.0.0.1); `external` — из сети (0.0.0.0) |

4. Скрипт поставит зависимости, скопирует файлы, создаст systemd-сервис
   `bookmarks` (автозапуск при загрузке, автоперезапуск при сбое), проверит
   запуск и напечатает адрес.

5. Откройте адрес в браузере и зарегистрируйтесь: **первый зарегистрированный
   пользователь автоматически становится администратором** (ему доступна
   админ-панель).

### Непрерактивная установка

```bash
INSTALL_DIR=/opt/bookmarks PORT=8765 BIND=external sudo bash install.sh
```

`BIND`: `external` (0.0.0.0) или `internal` (127.0.0.1).

### Доступ по внутреннему адресу (internal)

Если выбран `internal`, приложение доступно только с самого сервера.
Судомашнего компьютера удобнее всего через SSH-туннель:

```bash
ssh -L 8765:localhost:8765 <юзер>@<адрес-сервера>
```

после чего в локальном браузере открыть `http://127.0.0.1:8765`.

## Обновление

- **Проверка**: пункт **«О программе» → «Проверить обновления»**.
  Если появится новая версия, об этом же будет напоминать бегущая строка
  в статус-баре (видна администраторам).
- **Обновление**: кнопка **«Обновить»** — сервис на несколько секунд
  останавливается, файлы заменяются (**данные не трогаются**), сервис
  перезапускается. Страница перезагрузится сама.

Новые версии публикуются в папке `update/` на GitHub
(архив с именем `update_vX_Y_Z.tar`, например `update_v1_4_2.tar`).
Локально (офлайн) архив можно положить в `update/` рядом с установкой —
он будет найден без интернета.

## Бэкапы

- **Вручную**: `sudo /opt/bookmarks/backup.sh` — согласованная копия базы
  появляется в `data/backups/` (хранится 7 последних копий, старые
  удаляются; `KEEP=14 ./backup.sh` — изменить число).
- **Автоматически** (каждый день в 03:00):

  ```bash
  sudo crontab -e
  0 3 * * * /opt/bookmarks/backup.sh >> /var/log/bookmarks-backup.log 2>&1
  ```

- **Восстановление**: `sudo systemctl stop bookmarks` → заменить
  `data/bookmarks.db` на файл из бэкапа → `sudo systemctl start bookmarks`.

## Полезные команды

| Задача | Команда |
|---|---|
| Статус сервиса | `systemctl status bookmarks` |
| Журнал (живьём) | `journalctl -u bookmarks -f` |
| Перезапуск | `sudo systemctl restart bookmarks` |
| Список пользователей | `sudo /opt/bookmarks/.venv/bin/python /opt/bookmarks/manage.py list-users` |
| Сбросить пароль | `sudo /opt/bookmarks/.venv/bin/python /opt/bookmarks/manage.py reset-password <юзер>` (новый пароль напечатается) |
| Заблокировать / разблокировать | `… manage.py lock-user <юзер>` / `… manage.py unlock-user <юзер>` |
| Сделать администратором | `… manage.py make-admin <юзер>` |

## Смена порта или адреса доступа

1. `sudo nano /etc/systemd/system/bookmarks.service` — поменяйте `--host`
   и `--port` в строке `ExecStart`;
2. обновите порт в файле `install.json` в каталоге установки
   (автообновлятель после обновления проверяет сервер именно на этом порту);
3. `sudo systemctl daemon-reload && sudo systemctl restart bookmarks`.

Если меняете порт при внешнем доступе — не забудьте правило файрвола:
`sudo ufw allow <порт>/tcp`.

## Удаление

```bash
sudo systemctl disable --now bookmarks
sudo rm /etc/systemd/system/bookmarks.service
sudo rm /etc/polkit-1/rules.d/90-bookmarks.rules
sudo rm -rf /opt/bookmarks    # вместе с данными (data/)
sudo userdel bookmarks
sudo systemctl daemon-reload
```
